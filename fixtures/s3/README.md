# S3 — 3D fixtures

Original procedural models written by `npx tsx tools/make-glb.ts fixtures/s3` (CC0). They are real glTF 2.0 binaries:
one node and one mesh per part, named by part id, with a base-colour material.

| File | Parts |
| --- | --- |
| rocket.glb | nose, body, window, fin_a, fin_b, fin_c, flame |
| lighthouse.glb | cap, lamp, gallery, tower, stripe_1, stripe_2, door, base |
| planet.glb | globe, ring, moon (spare) |

No downloaded or user-provided models were available. Real-world glTF files (textures, skins, multiple primitives per node) have not been tested yet.
