# 方案修订（2026-11）

在原始规划基础上，根据前两个提交的实际渲染结果做的调整。

## 1. 关键调整：用「SDF 部件场」统一 M2 + M4

**原方案**把语义部件（M2）、轮廓插值（M3）和液态（M4）当作三个模块，作品里串联调用。实际做下来的问题有：

- 每次交接（部件 → 液态 → 部件）都是一次表示切换，最容易出现跳变。旧版墨滴→飞鸟在 25%→50% 就是这样。
- 椭圆 metaball 表达不了触手、伞骨、羽毛这类细长部件。
- 液态层只有一种材质，融合处颜色无法过渡。

**新方案**：每个部件写成「骨架曲线 + 半径曲线」（或椭圆、盒、半平面），按顺序做平滑并、差、交。

| 原需求 | 在部件场里的实现 |
| --- | --- |
| 一对一部件变形 | 等点数骨架逐点插值 `blendStroke` |
| 一对多分裂 | 两条初始重合的骨架，沿弧长错开分离（拉链式） |
| 多对一融合 | 骨架靠近 + 融合半径增大 |
| 液化 / 融化 / 黏连 | 融合半径 + 低频边缘扰动 wobble |
| 孔洞、断裂、重连 | 差集图元 / 半平面裁切滑开 |
| 材质过渡 | 颜色、光泽、透光度随融合权重混合 + 贴花 |
| 立体感 | 由距离场重建膨胀高度：高光、次表面透光、投影 |

这样一来，部件对应关系就是骨架点的对应关系，液态感来自融合半径，两者在同一表示里随时间连续变化，不再有交接。

M3（Flubber 轮廓）和 M5（粒子）保留，用于对应的效果。M6（Three.js）保留作真实 3D。

## 2. 创意规划器（M1）的补充规则

见 `skills/creative-morph/references/planning.md`。新增的四个手法在 Gate 1 中验证有效：

1. **环境起因**：水面上升唤醒雨伞，雨丝变成气泡。
2. **预示**：溅出的墨点正好落在未来羽尖的位置，羽毛长出来去接住它们。
3. **物质搬运**：伞尖金属熔成珠子，滑下后一分为二成为双眼。
4. **目标专属动作**：章鱼喷射游动和眨眼、鸟离开纸面振翅、蝴蝶起飞。

## 3. 机制扩展（Lab）

对照原规划盘点后，Skill 原先只有「液态部件场 / 粒子 / 轮廓 / 网格」四种机制。很多 A→B 题目（脆性物体、线稿、植物、实心 3D 物体、文字）缺少合适的手段。本轮新增 5 个 Lab 作品。每个对应一种可复用的引擎能力，全部可在播放器中拖动查看：

| Lab | 机制 | 新增引擎能力 |
| --- | --- | --- |
| `lab/glyph-fish` 鱼字 → 锦鲤 | 字形笔画即骨架；⺈→头、田→鳞身、底横→分叉尾 | 笔画书写动画 + 部件场 |
| `lab/vase-whale` 青花瓶 → 鲸 | Voronoi 碎裂，碎片正面画瓶、背面画鲸，空中翻面 | `effects/fracture.ts` |
| `lab/line-cat-deer` 猫 → 鹿 | 一笔画：整幅画始终是一条线，被抽出后重绘 | 等点重采样 + 飞行曲线 |
| `lab/seed-rabbit` 种子 → 兔 | 空间殖民生长，树冠只长在兔子轮廓内 | `effects/growth.ts` |
| `lab/donut-mug` 甜甜圈 → 咖啡杯 | 3D 光线步进 SDF，亏格 1 同胚：环 = 把手 | `renderers/shader-layer.ts` |

还缺的机制（折纸、翻牌、揭开、烟雾流体、鸟群、影子戏、微距穿越、燃烧、结晶、磁流体）列在 `skills/creative-morph/references/effect-catalog.md`，并附实现草图。

## 5. 下一步建议（按优先级）

1. **Gate 4 盲测**：新会话只给 Skill，例如「钥匙→蜂鸟」「茶杯→水母」，看 Agent 能否独立完成计划、场景和导出。根据失败点修订 Skill。
2. **部件场 + 粒子混合**：在 `sdf-gl` 中加入「从距离场表面采样粒子」的工具，让液态物体可以直接粒子化，再重组。
3. **3D 部件场**：raymarch 版本，图元和骨架工具不变，加深度与真实遮挡，替代现在前后两层的 2.5D 近似。
4. **离线导出加速**：当前 SwiftShader 软件渲染下约 1 秒/帧（720p）。有 GPU 的 Windows 机器上应快一个数量级。可在 `tools/browser.mjs` 增加 `--use-gl=angle` 开关。
5. **可选 AI 视频适配器（M8）**：维持原规划，不阻塞主线。
