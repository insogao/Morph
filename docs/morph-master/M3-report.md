## 4. 过程中发现并修好的问题

1. **同一部件里不同元素的环被合在一起判断洞**：触角的圆形末端和触须重叠，被当成了洞 → 改为每个元素单独成形，元素之间永远不会互相挖洞。
2. **包含判断只看第一个点**：重叠的环被当成“在里面” → 改为采样点全部在内才算包含。按 fill-rule 判断：nonzero（SVG 默认）下，只有绕向相反才是洞。
3. **BlendSpace 共享采样会削掉目标的尖角**（约 2 px）→ 把每个目标的拐角加入共享采样。

## M3b：矢量 → SDF 交接（2026-11-07）

### 方案

**矢量负责几何，SDF 负责材质。** 矢量轨道（对应关系、部件映射）继续驱动形状；每一帧的轮廓变成 SDF 多边形图元，由部件场渲染。材质参数随时间变化：倒角厚度、光泽、边缘扰动、片与片之间的融合半径、透光、颜色。两条轨道每一帧画的都是同一个轮廓，所以交接不会跳变：“墨字 → 液态 → 生物”就是同一段连续几何上的一份材质时间表。

### 交付

| 文件 | 内容 |
| --- | --- |
| `renderers/sdf-gl.ts` | 新增 `polygon` 图元：顶点存在另一张浮点纹理里（最多 32768 个），精确距离 + 奇偶符号；洞用 `op: "subtract"`。`transformPrims` 支持多边形。原有 SDF 场景全部不受影响 |
| `vector/sdf-bridge.ts` | `framePrims`：外轮廓 union（可融合），洞 subtract；`frameDecals`：只上色不改几何；`simplifyRing`：保留拐角、按弧长取点，控制在 ≤ 160 点 |
| `lab/mm-glyph-koi`（MM09） | 真实字体（Noto Sans SC 900）“鱼” → 锦鲤：水滴落下（起因）→ 字躺倒并液化，田字的格子闭合 → 上部变身体、底横变尾巴并分成两叶、鳍从身体长出 → 斑纹和眼睛浮现，游走 |
| 播放器 `render` 选项 | `morph.json` 加 `"render": { "track": "sdf", … }`，每个参数写 [前, 中, 后] 三个值，任何部件形变都能改用液态材质；叠在其他部件上的小部件自动改为贴花 |
| ~~`lab/mm-umbrella-jellyfish-liquid`（MM10）~~ | 已删除，见 M3b.1 节 |
| 文档 | `vector-track.md` 新增交接一节；`svg-parts.md` 加 3b 节；`part-mapping.md`、`SKILL.md` 加了指引 |

### 过程中发现并修好的问题

1. **字体与预期不符**：Noto Sans SC 里的“鱼”是 2 片，不是 3 片（⺈ 和田连成一个轮廓，田的 4 个格子是洞）。场景里写了片数检查，构建时直接报错，没有悄悄跑错；已改为 2 片的映射。
2. **交接点的隐藏跳变**：旋转在 2.6 s 结束，交接却在 2.5 s，会跳约 4.5° → 让旋转先完成（2.4 s）。在 2.45、2.5、2.55 s 截帧确认连续。
3. **颜色经过死灰**：墨黑直接变奶白，中段是石头一样的灰 → 身体颜色改为 墨 → 橙 → 奶白 三段。
4. **眼睛被吞掉**：平滑 union 会把身体内部的小部件吸收掉（身体的距离值更小，颜色跟着身体走）→ 播放器自动把“中心落在已画几何里”的部件改为贴花。这对斑点、条纹、眼睛普遍适用。

### 液态粘连问题的根因与通用修复

- **根因**（逐帧确认）：融合半径作用于**所有**部件之间。伞杆分裂成 4 根触手时，4 个分身重叠，被融合成一根粗柱，随后撕扯出触手之间的蹼。也就是说，“正在分开的东西”被液态桥连在了一起。
- **修复（在播放器里，通用）**：`render.fuse` 融合组。每组渲染成单独的 SDF 图层，液态桥到不了组外的部件。默认规则：融合（N→1）的来源同组，因为它们在汇合；分裂的分身永远不同组，因为它们在分开；其余部件各自独立。
- **换例子**：删除了水母液态版。新的 MM10 是**蜡烛 → 郁金香**，液态本身就是故事：
  - 火焰闪动（起因）；
  - 蜡融化坍塌，和烛滴、烛台一起汇成一滩，变成花盆；
  - 叶子从熔融的盆里长出来；
  - 烛芯拉长成花茎；
  - 火焰从黄色冷却成橙色花苞，分成三片花瓣；
  - 最后花在风里摇曳，花瓣微微开合。
  
  第一版里烛滴直接从蜡烛飞向叶子的位置，悬在半空，不对：融化的蜡应该往下流。已改为烛滴并入蜡池，叶子再从盆里长出。全程只有 `morph.json`。
- 文档：`svg-parts.md` 3b 节写入两条规则：液态桥只在 fuse 组内；液态适合真正会融化、流动、汇聚的题材。

## M3b.2：液态“粘连不舒服 / 像 bug”的排查（2026-11-07）

**反馈**：液态粘连还是不好看。可能是 3D 质感加粘连让人不舒服，也可能是粘连随物体运动出现瞬间移动、消失，看起来像 bug。

### 先测量：新工具 `tools/pops.mjs`

以 60 fps 渲染，计算每帧与前一帧的平均像素变化，找出比邻近帧大很多的帧（突变），并保存前后对比图。平滑运动每帧都只变一点；像 bug 的跳变，会在一帧里变很多。

MM10 在形变窗口内测出 **6 处突变**（变化量是邻近帧的 3.4–6.3 倍），证实了用户的直觉。

### 三个根因（都是引擎 bug）

1. **部件在“几何”和“贴花”之间闪烁**（2.6、2.75、2.85、3.0、4.4 s）。“叠在别的部件上的小部件改为贴花”这个判断原来每帧重做：蜡、烛滴、烛台汇合时，或花瓣互相重叠时，某个部件的中心一进一出，几何就在单帧内消失又出现，看起来就是“瞬间移动、消失”。→ 改为只根据原图**判断一次**：只有在自己那张图里又小、又落在另一个部件内部的部件（眼睛、斑点）才是贴花，整个形变期间不变。
2. **新生部件的液态桥一出现就是满尺寸**（3.9 s）。叶子刚出生时几乎没有大小，却立刻和盆之间搭起完整的桥（26 px 半径的约四分之一），一帧之内就冒出来。→ 桥的半径不超过部件自身大小，随部件一起长大。
3. **立体光泽质感**：在扁平插画上，倒角加高光的“果冻感”确实显得别扭。→ 新增 `flat` 材质：纯色，保留平滑的液态轮廓，没有倒角、光照和高光（经典的运动图形 goo 效果）。`render.style` 默认 `flat`，`glossy` 可选。

### 结果

- 修复后 MM10 **无突变**，平均帧间变化从 0.134 降到 0.064（抖动一并消失）。
- 对全部 MM 场景跑了突变检测：
  - MM01、MM02、MM04、MM05、MM07、MM08、MM09、MM10、MM11 无突变；
  - MM03 剩一处是 HUD 步骤标签切换颜色，不是几何；
  - MM06 的一处是背景水纹在飞行速度峰值处的连续运动（比值 3.0，刚过阈值）。
  
  检测阈值提高到 0.5，避免背景颜色量化（整帧变化 1 个色阶）造成误报。
