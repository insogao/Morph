## 2. 关键设计：逐字配对

最初用“公共子序列”锚定相同字母，结果很差。MORPH → MASTER 会锚定 M 和 R，中间 1 个 O 要对 4 个字母，最后只有一个字母真正在变，另有 3 个凭空出现、2 个消失。

改为编辑距离对齐：

- 同一个字母保持不变，代价 0；
- 换成另一个字母，代价 1；
- 消失或新生，代价 1.45；
- 另加移动距离的代价。

规则的含义是：**宁可让字母变成字母，也不要一个消失、另一个凭空出现**。结果：

- MORPH → MASTER：M 保持；O→A、R→S、P→T、H→E；R 新生。
- MASTER → 变形：A→变、T→形，其余 4 个字母飞进最近的汉字。
- 变形 → ✱：形 → ✱，变 并入其中。

- **浏览器**：在预览面板里播放正常，控制台没有错误。

## 4. 过程中修好的问题

- 新生 / 消失字槽的底板用的是缓动进度，字形用的是延迟缩放，两者不同步，空底板先出现，看起来像一个黑点 → 改为底板跟随字形当前的包围盒。
