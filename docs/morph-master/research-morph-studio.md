## 1. 产品是怎么工作的【T】

依据：官方教程逐帧截图，加上语音转写（`source/ms-tutorial-J6mlT_2G8BE.whisper.srt`，Whisper small 自动转写，个别词可能听错）。

**支持的输入**（作者原话）：SVG 文件、Shape 图层、文字图层、Illustrator 文件。也就是“AE 能在内部生成形状的一切东西”。**位图不在其列。**

**面板只有三块**：`Load Selected Layers` 按钮；`PREVIEW & MAP` 画布；`MORPH SEQUENCE` 条加 `Generate Morph` 按钮。

### 1.1 自动对应 + pins（核心）

- **算法思路**（作者原话大意）：先计算一个“数学上好的顶点分布”作为基线；**每加一个 pin，都在满足全部 pin 的前提下把所有顶点重新计算一遍**。所以 pin 是全局约束，不是只改局部的一个点。
- 编辑模式下两个形状叠在一起显示为线框，叠加透明度可调、可关。白色大点是原始顶点，橙色小点是生成的拓扑点。
- 操作：
  - 先点一个形状上的点，再点另一个形状上的对应点；
  - 那个位置没有点时，按住 Alt 在轮廓上新建一个点；
  - Ctrl/Cmd 点击删除 pin；另有撤销、重做、`Clear Pins`。
  - 新版允许**一个点连多个点**（一对多连接），也允许多个点重叠在同一位置。
- `Show point connections`：显示每个顶点从 A 到 B 的连线，作者说这能“看出形变为什么是这个样子”。可以全部显示，也可以只在鼠标悬停时显示。
- **故障检测（fault）**：两个或更多顶点从 A 走到 B 的轨迹交叉时，插件会警告。原因可能是形状本身，也可能是 pin 放得不好；改 pin 就能修。
- **旋转对齐**：M ↔ E 很难变，作者在设置里把 E 预先旋转 90°，自动结果立刻好很多。在文字形变里也可以单独旋转某个字母。
- `Isolate selected paths`：子路径太多时，只显示当前这一对字母或子路径。
- 示例里一般只放 2–6 对 pin。**自动对应负责大部分点，pin 只修关键位置。**

### 1.2 预览

`Done` 后进入预览：播放、进度条、`Current Step` / `Full Sequence` 切换（只看当前段或看整条序列）、`Edit` 回到编辑。

截图里，心形 ↔ 星形和 D → H → M → E 的中间帧普遍偏圆，尖角变钝。原因可能是顶点线性插值，也可能叠加了回弹【C】。

### 1.3 输出

- `Generate Morph` 生成一个 `Morph Sequence` Shape 图层，只有 `Path` 和 `Color` 两条原生关键帧。原始图层保留并隐藏。
- **结论**：插件负责“重排顶点，让两边一一对应”；帧间插值交给 AE 原生的路径关键帧。缓动直接用 AE 的 Easy Ease 和曲线编辑器。
- 输出选项有两个：
  - `Animate layer transforms`：同时把图层位置等变换从 A 插值到 B；
  - `Bounce`：加一个效果，参数为 Amplitude / Frequency / Decay（示例默认 12 / 3 / 5，又改成 8 / 2 / 2）。回弹可以和 Easy Ease 关键帧一起用；复制关键帧就能做循环。
- **描边 ↔ 填充**的形状之间也能形变，填充色和样式属性会自动插值。

### 1.4 序列

点选图层后按 `+` 加入序列，可以拖动调整顺序；每一段单独编辑 pin。生成后同一条 Path 属性上有多个关键帧，拖动关键帧就能改每段的速度。

### 1.5 多形状 ↔ 一形状（05:49）

- 沙漏（1 条路径）↔ X 加四颗菱形（5 条子路径）。载入后默认只匹配第一条子路径，需要用 `Path 1 of 5` 切换器逐条处理。
- **消失点（vanishing points）**：没有配对的子路径会缩小到一个目标点后消失（反过来就是从这个点长出来）。目标点默认在中间，可以拖动。作者把每颗菱形的目标点挪到它自己的中心，让它们“原地缩小”，而不是“飞向中央”。
- 在编辑器里也可以把某条子路径从指定点缩小（D → H 的例子里用了这个）。

### 1.6 文字（12:02）与单独图层（14:10）

- 文字图层先转成轮廓。单词之间按字母配对，不同位置的字母也能配（例如 M 配 D）。
- 示例用第三方面板 `TextExploder` 把句子拆成单词图层，**按词拆分不是插件自带的功能**。
- `Separate shape layers`：把一个多子路径的 Shape 图层拆成多个图层，每个字母一层，之后可以单独做位置动画或手动错开时间，做出逐字波浪的效果。

## 2. 宣传片里的效果【V】

| 画面 | 拆解 | 归属 |
| --- | --- | --- |
| 文字 MORPH → X 形 → 八瓣花 | 文字转轮廓后与图标互变 | 插件 |
| 线框形状互变，留下几十层残影 | 轮廓历史叠加（echo），伪挤出 | AE（Echo 或复制图层）【C】 |
| 环 → Y 形 → 木字形 → 人字形 → 环 | 多形状循环序列 | 插件序列 |
| 六边形图标边旋转边改变缺口 | 形变 + Transform 同时插值 | Animate layer transforms |
| 卡片中 F→H→Z→K，气泡 → 电话 | 每个字槽独立形变、错开；卡片本身挤压 | 单独图层 + 手动错开 + bounce【C】 |

整体风格：**扁平纯色、锐利矢量的运动图形**。

## 3. 对我们的结论

1. **Morph Studio 的价值 = 好的自动对应 + 全局重算的 pin 约束 + 可视化诊断**（顶点连线、交叉警告），外加序列、消失点、旋转对齐和回弹。渲染、缓动、残影、错开都靠 AE。网页版这些都要自己做，也就能做得更完整。
2. **直接借鉴的机制**（全部写进 PLAN 第 2 节）：
   - pin 作为全局约束，加 pin 后整体重算；支持一对多；
   - 轨迹交叉检测（fault），在自检里报告；
   - 消失点：未配对子路径缩向可指定的目标点，默认是它自己的中心；
   - 预旋转对齐（让 E 旋转 90° 再配 M）：自动搜索最佳旋转角，也允许手动指定；
   - 单段预览 / 整条预览；只看当前子路径；
   - 回弹参数 Amplitude / Frequency / Decay。
3. **我们要超过它的地方**：
   - 插值质量：拐角对拐角、rotational 插值、控制柄防折角，让中间帧保持“有形”。验收时与线性基线并排对比。
     **M1 实测更正**：对应关系做好之后，线性插值的中间帧并不会糊成圆团，所以质量主要来自对应关系本身。intrinsic 插值的优势只在需要转动的题目上（例如 E → M）。见 `M1-report.md` 第 3 节。
   - 不用手动：逐字错开、残影、容器挤压做成内建算子；“按词拆分”也内建。
4. **对 AI 的意义**：AI 不能像人一样拖点，所以 pin 要能**用名字表达**（`top`、`sharpest-left`、`corner:3`），自检要能**用数据说话**（交叉数、有形度）。调试视图要能截图给 AI 看连线。
5. **它没有的，我们补上**：
   - 一分多（Split）；
   - 同一形状朝多个目标的权重混合（BlendSpace）；
   - 位图和照片；
   - 有机液态（SDF 部件场）。
